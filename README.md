# React Native Bottom Sheet

![](https://img.shields.io/npm/v/@wekor/react-native-bottom-sheet)

React Native Bottom Sheet provides native bottom-sheet components for React
Native.

```sh
npm i @wekor/react-native-bottom-sheet
```

Learn more in
[the documentation](https://wekor.github.io/react-native-bottom-sheet).
